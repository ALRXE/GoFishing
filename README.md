# 去钓鱼！GoFishing!

**版本：v1.1.1**

给游戏加入一套简单完整的钓鱼玩法！

带上 **简易钓鱼竿** 外出拾荒，就有机会钓到不同重量的 **小黄鱼** 和 **大黄鱼**。钓到大鱼后，还能使用 **生锈的片肉刀** 加工成按原鱼重量计算的 **生鱼片**。

## 模组内容

- **简易钓鱼竿**：佩戴后把拾荒变成钓鱼，每轮有 80% 概率获得鱼类
- **小黄鱼**：重量 50–200 克
- **大黄鱼**：重量 300–2000 克
- **生锈的片肉刀**：既能作为武器，也能加工大黄鱼
- **生鱼片**：成品重量为原鱼的 60%，价值和热量随重量变化
- **钓鱼商人**：每 7 天来访一次，出售钓鱼工具并随机携带鱼货
- 两种鱼也有 **5% 概率**出现在匹配的原版食品货源中

## 安装方法

需要安装 **MelonLoader**。

将压缩包中的全部 DLL 放入：

\```text
Probably Stolen Playtest/Mods
\```

完全重启游戏即可。

## 注意

- 不要漏装压缩包中的两个 Runtime
- 更新时直接覆盖旧文件
