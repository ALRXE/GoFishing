# 去钓鱼！GoFishing!

给游戏加入一套完整的钓鱼与鱼类加工玩法！
带上钓鱼工具前往拾荒，捕获不同种类和重量的鱼。钓到的鱼可以直接出售或食用，也可以进行切片、风干、腌制、辣味加工、油浸等处理。
部分特殊鱼还可以获得独特材料，并进一步用于其他物品的制作。

## 主要内容

目前共有多种捕鱼工具：
- 简易钓鱼竿
- 双钩钓鱼竿
- 碳纤维钓鱼竿
- 渔网
不同捕鱼工具拥有不同的鱼池、捕获数量和定位。

目前可以捕获：
小黄鱼 / 大黄鱼 / 沙丁鱼 / 彩虹鱼 / 净水鱼 / 火山鱼 / 电鳗 / 玻璃鱼 / 独角剑鱼
不同鱼类拥有各自的重量范围、热量和按重量计算的价值。
部分鱼适合直接出售，部分鱼更适合进行特定加工，也有一些特殊鱼的主要价值来自它们身上的特殊部位。

### 加工鱼类
**生锈的片肉刀**既可以作为刀类武器，也可以用于处理鱼类。
目前可以加工：
- 大黄鱼 → 黄鱼鱼片
- 独角剑鱼 → 紫色鱼片 + 剑鱼吻突
- 彩虹鱼 → 彩虹鱼片
- 净水鱼 → 净水鱼肉 + 净化囊
- 火山鱼 → 火山鱼片 + 发热腺体
- 电鳗 → 电鳗鱼片 + 导电鱼筋
- 玻璃鱼 → 透明鱼膜
不同鱼类拥有不同的加工收益。

### 风干
使用 **风干架** 可以将鱼制作成鱼干。
不同鱼类拥有不同的：
- 风干时间
- 重量损耗
- 成品价值
- 热量
部分鱼非常适合风干，而部分鱼风干后会损失大量价值，需要根据鱼的种类选择合适的加工方式。

### 罐装鱼肉
使用 **封装罐头** 可以进行多种鱼类加工。
目前包含：
- 腌制鱼肉
- 辣味腌鱼
- 油浸鱼
不同加工方式需要对应的材料，例如：
- 盐
- 超级盐
- 辣椒
- 火爆辣椒
- 鱼油
鱼类和调料会影响最终成品的重量、品质及价值。
部分鱼也会对特定加工方式产生额外效果。

### 特殊材料
处理部分特殊鱼时可以获得：
- 净化囊
- 发热腺体
- 导电鱼筋
- 透明鱼膜
- 剑鱼吻突
这些材料除了可以出售外，还可以使用 **加工台** 制作其他物品。

### 钓鱼商人
钓鱼商人主要出售捕鱼和加工相关设备，包括：
- 各种钓鱼竿
- 渔网
- 生锈的片肉刀
- 风干架
- 加工台
- 封装罐头
- 部分加工材料

### 渔民
渔民会定期有机会来访。
主要出售：
- 盐
- 辣椒
- 鱼油
- 封装罐头
- 随机鱼类
如果需要大量加工材料或者想直接购买鱼类，可以留意渔民来访。

## 安装方法
需要提前安装 **MelonLoader 0.7.3**。
完全退出游戏后，将以下四个文件放入游戏的 `Mods` 文件夹：
- `ItemForgeRuntime.dll`
- `PSItemPack_Gofishing.dll`
- `CharacterForgeRuntime.dll`
- `PSCharacterPack_FishingFriends.dll`
如果已经安装旧版本，请覆盖旧文件后重新启动游戏。

玩家只需要安装以上四个 DLL，**不需要安装 ItemForge 或 CharacterForge 制作程序**。

本 Mod 基于 ItemForge 和 CharacterForge 制作。
