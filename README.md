# 去钓鱼！GoFishing!
给游戏加入一套简单完整的钓鱼玩法！
带上简易钓鱼竿前往拾荒，捕获不同种类的鱼；你可以直接出售或食用，也可以使用片肉刀加工鱼片，或者加入盐和调料腌制成罐装鱼肉。

## 主要内容
拥有 **简易钓鱼竿** 后进行拾荒，可以获得专属鱼类产物，本 Mod 共包含 13 个自定义物品。
目前可以捕获：小黄鱼/大黄鱼/独角剑鱼/彩虹鱼
不同鱼类拥有各自的重量范围、热量和按重量计算的价值。稀有鱼出现概率更低，但可能拥有更高的售价。

> 钓鱼竿当前有 80% 的专属产出概率。未触发时，本轮拾荒不会获得物品。

###  加工鱼片
**生锈的片肉刀**既可以作为刀类武器，也可以用来加工鱼类。
目前支持：
- 大黄鱼 → 黄鱼鱼片
- 独角剑鱼 → 紫色鱼片
- 彩虹鱼→ 彩色鱼片

### 腌制鱼肉
使用 **封装罐头**可以制作腌制鱼肉：
1. 将鱼放入封装罐头
2. 根据需要加入盐或超级盐
3. 点击“开始腌制”
4. 等待 2 个游戏日
5. 双击罐头取出成品
鱼类和调料会影响最终成品的重量、品质及价值。
- 普通盐可以小幅提升品质
- 超级盐可以大幅提高品质和价值
- 部分特殊鱼类也会影响腌制结果

### 钓鱼商人
- 第 1 个游戏日首次进入来访候选
- 此后每隔 6 个游戏日再次来访
- 固定出售钓鱼竿、片肉刀、封装罐头和盐
- 随机出售不同鱼类及高级鱼片

## 安装方法
需要提前安装 **MelonLoader 0.7.3**。
完全退出游戏后，将以下四个文件放入游戏的 `Mods` 文件夹：
- `ItemForgeRuntime.dll`
- `PSItemPack_Gofishing.dll`
- `CharacterForgeRuntime.dll`
- `PSCharacterPack_FishingFriends.dll`
覆盖旧文件后重新启动游戏即可。
玩家只需要安装这四个 DLL，**不需要安装 ItemForge 或 CharacterForge 制作程序**。
